# 🚀 Recruitment Automation Skill

## Skill Overview

**Recruitment Automation** is a production-ready Claude Code skill that automates your entire recruitment pipeline - from candidate screening to compliance checking - saving 40+ hours monthly per recruiter.

### What This Skill Does

```
Your Workflow:
1. Candidate applies → Automatic resume parsing
2. AI scores candidate against job requirements
3. Sends screening email automatically (if qualified)
4. Parses email responses and scores answers
5. Validates work authorization/visa status
6. Routes qualified candidates to phone screening
7. Tracks all metrics in spreadsheet
```
