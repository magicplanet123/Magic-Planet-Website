# 🎯 B2B Lead Hunter Skill

## Skill Overview

**B2B Lead Hunter** automates your entire B2B prospecting process. Find companies, extract hiring manager contacts, and generate personalized outreach emails - all in one skill.

### What This Skill Does

```
Automated Workflow:
1. Define target companies (industry, size, location)
2. AI scrapes LinkedIn, company websites, databases
3. Extracts hiring manager contacts
4. Finds decision-makers' email addresses
5. Generates personalized cold emails
6. Tracks open rates, clicks, responses
7. Routes hot leads to sales team
```

## 🚀 Getting Started

### Step 1: Configure Target Market
```json
{
  "target_companies": {
    "industry": "SaaS",
    "company_size": "10-500 employees",
    "location": "USA, Canada",
    "funding_stage": "Series A+",
    "growth_signals": ["hiring", "funding", "partnerships"]
  }
}
```

### Step 2: Connect Data Sources
```
✅ LinkedIn (via Apify)
✅ Company databases (Hunter.io, Apollo)
✅ Email verification (ZeroBounce)
✅ CRM (optional: Salesforce, HubSpot, Pipedrive)
```

### Step 3: Generate Leads
```bash
# Run daily to get fresh leads
python b2b_lead_hunter.py --generate 100 --email-all

# Output:

# - 150+ contacts extracted
# - 150 personalized emails generated
# - 30-50 opens tracked
# - 5-10 responses logged
```
